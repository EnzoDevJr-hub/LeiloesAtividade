LeiloesTDSat
Sobre o Projeto
O LeiloesTDSat é um sistema de gerenciamento para casas de leilões desenvolvido em Java com interface gráfica (Swing). O sistema permite o cadastro de produtos para leilão, listagem dos itens disponíveis e controle de status de venda dos produtos.
Funcionalidades principais:

Cadastro de produtos para leilão
Listagem de produtos cadastrados
Controle de status dos produtos (A Venda / Vendido)
Conexão com banco de dados MySQL para persistência dos dados

Tecnologias Utilizadas

Java — Linguagem principal de desenvolvimento
Java Swing — Biblioteca para interface gráfica (GUI)
MySQL — Sistema de Gerenciamento de Banco de Dados (SGBD)
JDBC — API de conexão Java com banco de dados
MySQL Connector/J — Driver JDBC para MySQL (versões 5.1.47 e 8.0.21)
Apache NetBeans — IDE utilizada no desenvolvimento
